Core Capabilities

Built for Modern Academic Learning

Designed to deliver an intuitive and reliable digital classroom experience for faculty members and enrolled students.

📹

Video Lecture Streaming

High-definition video streaming with variable playback speeds (0.75x to 2x), wide cinema mode, and millisecond-accurate progress persistence.

  • ✓ HTML5 byte-range video streaming
  • ✓ Keyboard shortcuts (Space, M, F, Arrows)
  • ✓ Automatic watch completion thresholds
📝

Interactive Exam Runner

Timed online assessments with single-choice, multiple-choice, true/false, and short answer question banks with instant automated grading.

  • ✓ Dynamic countdown exam timers
  • ✓ Instant score calculation and answer review
  • ✓ Multiple attempts with highest score retention
📂

Assignment Submissions & Feedback

Seamless document and archive uploads with professor feedback, rubric evaluations, and weighted score calculation.

  • ✓ PDF and source code attachment support
  • ✓ Professor personalized feedback notes
  • ✓ Resubmission management workflow
📊

Comprehensive Gradebook Matrix

Real-time calculation of overall course standing, letter grades, weighted assignment ratios, and academic transcript records.

  • ✓ Automated weighted grade calculations
  • ✓ Academic letter grades (A, B, C, D, F)
  • ✓ Student cohort performance distributions
📅

Attendance & Performance Tracking

Faculty attendance session logs with present, late, excused, and absent statuses paired with early risk alert notifications.

  • ✓ Multi-status attendance management
  • ✓ At-risk student automated flagging
  • ✓ Full semester attendance percentages
🏅

Verifiable Badges & Certificates

Milestone achievements and cryptographic course completion certificates with unique verification UUIDs.

  • ✓ Six distinct academic badge categories
  • ✓ Publicly verifiable certificate links
  • ✓ Downloadable PDF achievement summaries
